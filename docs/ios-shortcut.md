# iOS 快捷指令配置：存到链接坞

这个快捷指令出现在 iOS 系统分享菜单中，把当前网页链接用**上传密钥**提交到 LinkDock，并显示保存结果。它不读取剪贴板，也无法查看或删除已保存的链接。

> 状态说明：本文是手动创建快捷指令的步骤，仓库目前**没有**提供可直接安装的签名快捷指令文件。步骤按 iOS 18 中文界面编写，尚未在真机上逐步验证；动作名称在不同 iOS 版本中可能略有差异（括号内为英文界面名称）。首次配置后请按文末“验证”一节确认。

## 准备

- 站点地址，例如 `https://linkdock.<你的子域>.workers.dev`
- 上传密钥（部署时设置的 `UPLOAD_KEY`，不是网页登录密码）

## 创建步骤

打开“快捷指令”App，点右上角 **+** 新建快捷指令，命名为 **存到链接坞**。

1. 点底部 **ⓘ（详细信息）**，打开 **在共享表单中显示**（Show in Share Sheet）。
   - 回到编辑页，顶部会出现“接收 **任何** 输入，来自 **共享表单**”。点“任何”，只保留 **URL**、**Safari 网页** 和 **文本**。
   - 点“如果没有输入”，选择 **停止并回应**（Stop and Respond），回应内容填：`没有收到链接，请从网页的分享菜单使用`。
2. 添加动作 **文本**（Text），内容填站点地址，例如 `https://linkdock.example.workers.dev`。点动作结果，**重命名**为 `站点`。
3. 添加动作 **文本**，内容填上传密钥，重命名为 `上传密钥`。
4. 添加动作 **从输入中获取 URL**（Get URLs from Input），输入选 **快捷指令输入**（Shortcut Input）。
5. 添加动作 **从列表中获取项目**（Get Item from List），选 **第一项**。
6. 添加动作 **如果**（If）：输入为上一步的“列表中的项目”，条件选 **没有任何值**（does not have any value）。
   - 在“如果”分支中添加 **显示提醒**（Show Alert），内容：`没有找到可保存的网页链接`；再添加 **停止此快捷指令**（Stop This Shortcut）。
   - 删除“否则”分支中的内容（保持为空），“结束如果”保留。
7. 添加动作 **获取 URL 内容**（Get Contents of URL）：
   - URL：插入变量 `站点`，紧接着输入 `/api/links`（整体形如 `站点/api/links`）。
   - 展开 **显示更多**：
     - 方法：**POST**
     - 头部：添加一个，键 `Authorization`，值输入 `Bearer `（注意末尾空格）后插入变量 `上传密钥`。
     - 请求体：**JSON**，添加一个 **文本** 字段，键 `url`，值插入第 5 步的 **列表中的项目**。
8. 添加动作 **获取词典值**（Get Dictionary Value）：获取 **值**，键 `message`，词典为上一步的 **URL 的内容**。
9. 添加动作 **显示通知**（Show Notification），内容插入上一步的 **词典值**。

完成后点“完成”保存。

## 使用

- Safari：打开文章 → 分享按钮 → 在 App 列表下方的操作中选 **存到链接坞**（首次可在“编辑操作”中把它加入收藏）。
- 微信公众号文章：微信 App 内置的“…”菜单不是系统分享菜单，不能直接调用快捷指令。可在“…”中选 **在默认浏览器中打开**，再从 Safari 分享；或选 **复制链接** 后粘贴到 LinkDock 网页。
- 首次运行时 iOS 会询问是否允许快捷指令连接站点，选 **始终允许**。

## 结果提示

服务端对每种情况都返回可直接显示的 `message`：

| 情况 | 通知内容示例 |
| --- | --- |
| 新链接已保存 | `已保存：https://mp.weixin.qq.com/s/…` |
| 已存在，移到顶部 | `已保存（已移到顶部）：…` |
| 链接无效 | `只支持 http 或 https 网页链接` 等 |
| 上传密钥错误或已更换 | `上传密钥无效，请检查快捷指令配置` |
| 服务未配置密钥 | `服务尚未完成配置，请检查部署密钥设置` |

只有出现“已保存”才表示链接已经写入数据库。网络不可用时，“获取 URL 内容”动作会由 iOS 直接报错（例如“无法连接到服务器”），此时链接没有保存。

## 验证

1. 在 Safari 打开任意文章，通过分享菜单运行快捷指令，应看到“已保存：…”通知。
2. 在电脑上打开 LinkDock 网页，几秒内应出现该链接（无需刷新）。
3. 把快捷指令中的上传密钥临时改错一个字符再运行，应看到“上传密钥无效…”，网页上不应出现新条目。改回后再次运行应显示“已保存（已移到顶部）”。

也可以在电脑上用同样的请求验证服务端：

```sh
curl -X POST "https://<站点>/api/links" \
  -H "Authorization: Bearer <上传密钥>" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://example.com/"}'
```
